# Кабинет у камина

Визуальная новелла с наставницей на основе ИИ. Вечер, кабинет-библиотека, камин и дождь за окном. За массивным столом сидит наставница, с ней можно говорить об учёбе, планах и жизни: текстом или голосом.

## Запуск

Нужен Node.js 20.12 или новее.

```bash
npm install
echo "ANTHROPIC_API_KEY=sk-ant-..." > .env   # можно пропустить и ввести ключ в игре
npm start
```

Затем откройте **http://localhost:3000**. Для голоса лучше подходят Chrome или Edge.

## Что умеет

- **Пиксель-арт без картинок.** Вся сцена рисуется кодом в `public/js/art.js` с разрешением 480×270. Каждый объект хранит цвет, нормаль, затенение и свечение. Поверх этого работает живое освещение (мерцающий камин, лампа, луна, свечи), контуры, виньетка и палитра с дизерингом.
- **Живая героиня.** Лицо меняется: 11 эмоций (модель сама выбирает их тегом `<mood>`), рот двигается во время речи, она моргает и переводит взгляд.
- **Чат в стиле новеллы.** Текст печатается по буквам, над окном диалога стоит имя говорящего, ремарки *в звёздочках* выделены курсивом. Есть журнал разговора.
- **Голос.** Наставница отвечает голосом (Web Speech API, озвучка идёт по предложениям прямо во время ответа). Говорить можно через микрофон, удерживая пробел, или в режиме «живой», когда она слушает сама после каждой своей реплики.
- **Всё настраивается в самой игре:**
  - имена наставницы и ваше;
  - её история и характер;
  - род обращения к вам и форма «ты»/«вы»;
  - 6 стилей речи и поле для своего;
  - длина реплик;
  - голос, его скорость и высота;
  - модель и вдумчивость.
- **Память.** Наставница сама запоминает важные факты о вас (тег `<remember>`). Посмотреть и поправить их можно в разделе «Память».
- **Атмосфера.** Треск камина и шум дождя синтезируются в браузере. Клавиша **H** прячет интерфейс, чтобы спокойно рассмотреть сцену.

## Устройство

| Файл | Что делает |
|---|---|
| `server.js` | раздаёт статику и передаёт поток ответа Claude через SSE (`@anthropic-ai/sdk`) |
| `prompt.js` | собирает системный промпт из настроек |
| `public/js/art.js` | движок сцены и героини |
| `public/js/app.js` | диалог, печать текста, голос, память, настройки |
| `public/js/presets.js` | стили речи и настройки по умолчанию |
| `public/js/ambient.js` | процедурный звук |

По умолчанию стоит модель Claude Opus 5.5 с низкой вдумчивостью, чтобы ответы приходили быстро. В настройках можно выбрать Sonnet 5.5 или Haiku 5.5. Для Opus и Sonnet включён серверный фолбэк на случай отказа модели. История и настройки хранятся в `localStorage` вашего браузера. Ключ, введённый в игре, уходит только на ваш локальный сервер.

Героиня — вымышленный ИИ-персонаж. На вопрос, кто она, она честно отвечает, что это ИИ.
