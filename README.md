# Звёздный конспект

Личный трекер учёбы и быта в виде пиксельной ролевой игры: дела дня дают опыт характеристикам, есть ветки развития, наставница с ежедневным заданием, квесты, трофеи и лавка наград.

Игра — один HTML-файл, который работает в браузере без сервера. В папке `docs/` она уже собрана как веб-приложение (PWA): её можно поставить на телефон иконкой на главный экран, и она открывается без интернета.

## Что где лежит

| Путь | Что это |
|---|---|
| `docs/index.html` | Готовое приложение. Его и нужно открывать |
| `docs/manifest.webmanifest` | Название, цвета и иконки для установки на телефон |
| `docs/sw.js` | Сервис-воркер: офлайн-режим и обновления |
| `docs/icons/` | Иконки приложения |
| `build/` | Исходники сборки: стили, рисунки предметов и значков, наставница, квесты, арты героини (`build/art/`) |
| `build/build.sh` | Пересобирает `docs/index.html` из исходников |

## Как превратить в приложение на телефоне

### Шаг 1. Включить GitHub Pages (один раз)

GitHub бесплатно раздаёт папку `docs/` как сайт.

1. Открой репозиторий на github.com → **Settings** → слева **Pages**.
2. В блоке **Build and deployment**:
   - **Source**: `Deploy from a branch`;
   - **Branch**: ветка, где лежит приложение (`main` после слияния pull request, или `claude/hopeful-fermi-3d646w`), папка **`/docs`** → **Save**.
3. Через 1–2 минуты вверху страницы появится адрес вида
   `https://mevlim.github.io/claide/`. Это и есть приложение.

> Pages на бесплатном тарифе работает только для **публичных** репозиториев. Если репозиторий приватный, его придётся сделать публичным (Settings → General → Danger Zone → Change visibility) или использовать GitHub Pro. В репозитории нет паролей и личных данных: отметки хранятся на самом телефоне, не в коде. Но арты героини и наставницы станут видны всем, у кого есть ссылка.

### Шаг 2. Перенести прогресс из версии на claude.ai

Сейчас твои отметки сохранены в аккаунте claude.ai. Приложение хранит данные на телефоне, поэтому их нужно перенести один раз:

1. Открой игру на claude.ai → вкладка **«Правила»** → раздел **«Сохранение»** → **«Показать копию данных»** → **«Скопировать»**.
2. Открой приложение по адресу из шага 1 → **«Правила»** → **«Сохранение»** → вставь текст в поле «Вставь сюда копию» → **«Восстановить»**.

### Шаг 3. Поставить на главный экран

**iPhone (Safari)**
1. Открой адрес приложения именно в **Safari**.
2. Нажми **«Поделиться»** (квадрат со стрелкой вверх) → **«На экран „Домой“»** → **«Добавить»**.
3. На экране появится иконка с героиней. Приложение открывается на весь экран, без адресной строки.

**Android (Chrome)**
1. Открой адрес приложения в **Chrome**.
2. Меню **⋮** → **«Установить приложение»** (или **«Добавить на главный экран»**) → **«Установить»**.

После первого запуска приложение работает и без интернета. Обновления приходят сами: при следующем открытии с интернетом.

### Важно про данные

- **Где хранятся.** Прогресс хранится в памяти браузера на этом телефоне. На компьютере и на другом телефоне он будет свой. Переносится через ту же «копию данных».
- **Резервная копия.** Иногда делай копию в «Правилах» и сохраняй её, например в заметку Obsidian. iPhone может очистить данные сайта, если приложением долго не пользоваться (больше нескольких недель), или если удалить иконку.
- **Иконка, не адрес.** Открывай всегда одной и той же иконкой или одним адресом: у разных адресов разные хранилища.

## Если нужен настоящий файл .apk для Android

PWA из шагов выше достаточно для повседневного использования. Если хочется именно установочный файл:

1. Открой **https://www.pwabuilder.com**, вставь адрес приложения → **Start**.
2. **Package For Stores** → **Android** → **Generate Package** → скачай архив.
3. В архиве есть `.apk`: перекинь его на телефон и установи (Android попросит разрешить установку из этого источника).

Для iPhone установочный файл без платного аккаунта разработчика Apple (99 $/год) и Mac с Xcode не сделать. Поэтому для iPhone вариант «На экран „Домой“» — основной.

## Как пересобрать после изменений

Нужен только Python 3, без дополнительных библиотек.

```bash
./build/build.sh
```

Скрипт упакует картинки из `build/art/`, соберёт страницу и положит готовое приложение в `docs/index.html`. Если меняешь что-то в оформлении или логике, увеличь версию кэша `CACHE` в `docs/sw.js` (например `konspekt-v2`), чтобы телефоны точно подхватили новую версию.
